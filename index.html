AnimBridge

Bridging AI-Generated Motion and 3D Character Animation Workflows

AnimBridge is an AI-assisted skeletal animation authoring system integrated into Blender. This page provides interactive animation results from the user study, allowing direct visual comparison between manual animation authoring in Blender and the final animations produced with AnimBridge.

16 study tasks 64-frame reference videos Interactive 3D comparison
User Study

What is shown on this page?

Each task provides a rigged target 3D character and a 64-frame reference video. The viewer presents the resulting animations from the two authoring conditions directly operated by participants: Blender-Manual, using Blender's native animation tools, and AnimBridge, using our AI-assisted workflow.

Scope. The fully automatic AnimBridge-Auto condition used in the paper's Task Outcome Quality analysis is reported in the paper and is not included in this interactive viewer.

How to explore

1
Play or scrub the reference video The Blender-Manual and AnimBridge animations stay synchronized with it.
2
Rotate the 3D views Drag inside a 3D panel to inspect the motion from different viewpoints.
3
Zoom for closer inspection Use the mouse wheel or trackpad to zoom in and out.
